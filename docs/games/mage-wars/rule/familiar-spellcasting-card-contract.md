## 运行时准入规则

以下规则由首批接入实现验证：

1. 魔宠计划牌必须单独存于对象，不得写入法师的 `preparedSpellCardIds`。
2. 魔宠只能在自己的生物行动阶段施法；再生点只能在部署阶段施法。
3. 对象法力必须先支付，法师法力只能补足差额。
4. 施法范围从实际对象区域计算；来源对象被摧毁前，已分配法术按规则处理，不能复用普通法师弃牌路径。
5. 对手视图只显示对象旁的卡背 / 数量，不显示对象计划法术身份。
