## 规则到画面裁定

| 规则结论 | 画面主体 | 设计决策 / 禁止项 |
| --- | --- | --- |
| 学徒竞技场是 `2x3` 六区域 | 竞技场与场上卡 | 场上卡全部有唯一 `data-zone-id`，A3 / B3 卡牌不被底部工作台遮挡 |
| 学徒法师生命 24、初始法力 10、聚魔 10 | 双方法师区 | 法师牌放在昵称上方，生命 / 法力 / 聚魔使用贴近法师牌的自制运行态 UI，不复现状态板 |
| 当前玩家有法术书与最多两张已计划法术 | 底部工作台 | 当前来源、已计划法术、法术书浏览器同时可见；收起大集合时保留数量、分类、分页和可读卡面 |
| 对手隐藏信息不能泄露 | 对手已计划法术 | 对手只显示卡背和数量，不显示正面或卡名 |
| 卡面已印刷费用、射程、目标、骰数和效果 | 卡牌本体 | UI 不复写这些字段；通过当前来源大卡、已计划槽和法术书浏览卡面解决可读性 |
| 目标确认态还未结算 | 目标与执行区 | 不显示骰子 / 伤害 / 状态结算层；确认后才进入结算浮层 |
