## 用户反馈转设计规则

| 用户反馈 | 设计裁定 | v26 画面要求 |
| --- | --- | --- |
| 法师角色卡放昵称上面更自然 | 接受 | 双方法师牌改为玩家身份竖向主语：法师牌在上，昵称 / 生命 / 法力 / 聚魔在下 |
| 中间应留给更重要的可支配法术区 | 术语校正：Mage Wars 没有“手牌”，对应的是法术书浏览与已计划法术 | 中央主舞台仍留给竞技场 / 当前结算；可支配法术以底部贴桌书轨承接，不压竞技场 |
| 已计划法术不应和法术书候选抢位置 | 接受并按规则改名 | 当前火球术只从“已计划法术”右侧来源槽出现；法术书候选不再重复显示当前火球术 |
| 法术书浏览没有沉浸感 | 接受 | 法术书浏览改为半嵌入桌面的书轨 / 牌托，候选牌必须完整收进轨道 |
| UI 太突兀没设计感 | 接受 | 删除无法说明交互职责的重面板；按钮、分类、分页保留 44px 命中区但改成低对比桌面材质 |

## 框体职责

| 非素材边界 | v26 裁定 |
| --- | --- |
| 法术书底部区域 | 改成半嵌入桌面书轨 / 牌托，只承载检索、分类、分页和归档入口；不得切边 |
| 已计划槽 | 保留为书轨右侧来源槽，与法术书候选并列但不同权重 |
| 玩家状态区 | 法师牌上置，状态读数下置，减少左右分裂和漂浮感 |
| 分类 / 分页 / 确认按钮 | 保留真实点击区；视觉降噪并使用桌面材质 |

## 前置硬失败禁止清单

- 出现手牌 / hand / opponent-hand 或等价默认持牌区。
- 当前火球术同时作为法术书候选主卡和已计划主卡，导致来源混淆。
- 已计划槽和法术书浏览同权重、同尺寸、同位置抢主焦点。
- 法师牌仍横放在昵称旁边，玩家身份区左右分裂。
- 法术书区域像悬浮后台面板，而不是桌面上的书轨 / 牌托。
- 攻击骰 / 伤害 / 燃烧离开西锁骑士当前目标。
- 用户批准前启动真实 Board/UI、真实页面 E2E 或移动端。
