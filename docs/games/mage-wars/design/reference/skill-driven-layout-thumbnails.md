# Mage Wars UI 方案低保真结构草图

> 状态：`layout-thumbnails / low-fidelity / awaiting-user-decision / artifact-blocked`。本文件只画结构关系，不是 Open Design 视觉稿，不包含最终视觉风格、素材裁切或可验收截图。用户选定方向前，不生成 Open Design artifact，不实现 Board/UI，不做移动端。

## 阅读方式

- `ARENA` = 标准竞技场与学徒 `2x3` 可用半场。
- `HUD` = 法师牌旁的水平生命 / 法力 / 聚魔 / 行动状态。
- `SPELLBOOK` = 法术书候选、分类、分页。
- `PREPARED` = 已计划法术 2 槽，当前真正可施放来源。
- `RESOLVE` = 当前施法 / 攻击结算链，包含目标、骰子、伤害 / 状态结果。
- `DOCK` = 确认 / 取消 / 跳过 / 等待响应等稳定动作入口。
- `DISCARD` = 弃牌堆公开归档入口，不是中央主链。

## 组合推荐草图：C + B + A + D

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ OPP HUD + hidden prepared backs + discard       compact phase/status       │
│                                                                            │
│          ┌──────────────────────────────────────────────┐ ┌──────────────┐│
│          │                   ARENA                      │ │    DOCK      ││
│          │ A1  B1                                       │ │ confirm      ││
│          │ A2  B2     source ─ RESOLVE ─ target         │ │ cancel       ││
│          │ A3  B3              dice + damage/status     │ │ wait/invalid ││
│          │ cards anchored in one zone                   │ │ no dice here ││
│          └──────────────────────────────────────────────┘ └──────────────┘│
│ PLAYER HUD      PREPARED 1        PREPARED 2                               │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ SPELLBOOK: categories | candidates | pages | public DISCARD edge       │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────────┘
```

### 为什么它是推荐组合

- `C` 保证当前动作链在主舞台，不再把骰子放边栏。
- `B` 保证底部法术书真的可浏览，而不是小牌堆角标。
- `A` 保证棋盘区域和卡牌归属不能再错。
- `D` 保证确认、取消、分页、分类、焦点和短错误足够可用。
