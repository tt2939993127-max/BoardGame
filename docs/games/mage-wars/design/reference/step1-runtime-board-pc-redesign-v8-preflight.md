## 规则到画面映射

| 规则结论 | 影响的画面主体 | v8 设计决策 / 禁止项 |
| --- | --- | --- |
| 学徒模式只用 `2x3` 半场 | 中央竞技场 | 用正式 `standard-arena.jpg` 作为第一视觉主体，并用六个轻量区域高亮呈现玩家当前可用半场；不另画抽象棋盘。 |
| 学徒法师生命 24、法力 10、聚魔 10 | 双方法师状态 | 贴近法师牌放自制生命条、法力条、聚魔短读数和伤害数值；不把状态板图片复现为主界面面板。 |
| 每名法师有行动标记和快速施法标记 | 法师牌附近 token | 使用 Mage Wars 自己的行动 / 快速施法素材；不使用普通开关或灰色状态 chip。 |
| 计划阶段最多准备 2 个法术 | 底部私密法术区 | 只放法术书入口、2 个已计划槽、弃牌堆入口和当前选中法术；不做满屏牌墙。 |
| 施法必须选择合法目标并可在支付前取消 | 当前行动槽 + 竞技场目标 | 火球术从已计划槽抬升，目标区域和西锁骑士卡本体高亮，`确认 / 取消` 贴近当前行动链。 |
| 对手未公开信息不能泄露 | 对手计划、未知法术书、隐性结界 | 只显示正式卡背、数量和归属，不展示正面或卡名。 |
| 攻击 / 法术结算使用攻击骰与效果骰 | 目标附近骰盘 | 攻击骰使用正式贴图；效果骰用蓝色 12 面程序化对象；骰盘靠近目标，不做独立黑盒。 |

## 框体职责回执

| UI 承载 | 处理 | 现实职责 |
| --- | --- | --- |
| 棋盘外大矩形框 | 删除 | 棋盘素材自带边界足够，开放桌面不再包硬框。 |
| 独立侧栏大 dashboard | 删除 | 对手计划、未知法术书和隐性结界改为真实卡背对象，贴桌面和宿主放置。 |
| 法师状态 HUD | 保留轻量 | 只保护生命、伤害、法力、聚魔等动态读数，贴法师牌，不成为整块状态板。 |
| 当前行动槽 | 保留轻量 | 承接选中法术、费用、目标和 `确认 / 取消`，按钮底板只服务点击命中。 |
| 目标高亮 | 保留轻量 | 服务真实区域 / 卡牌对象选择态，不使用代理列表。 |
| 骰盘 | 无底板 | 骰子直接落在目标附近，用阴影、光效和短标签区分。 |
