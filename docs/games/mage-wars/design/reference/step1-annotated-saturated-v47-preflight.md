## 层级模型

| 层 | 对象 | 可重叠规则 |
| --- | --- | --- |
| 背景层 | 桌面暗底、竞技场素材 | 可被低权重开放式 HUD 轻压 |
| 规则空间层 | A1/B1/A2/B2/A3/B3 六区域 | 不得被场上卡骑线或误判归属 |
| 物理对象层 | 法师牌、场上卡、法术牌、卡背、token、攻击骰 | 必须比外框和文字壳更像主体 |
| 主交互 overlay | 来源 / 目标高亮、路径线、法术书浏览、计划关系箭头 | 可压桌面和低权重边缘，不遮挡当前目标本体 |
| 结算 overlay | 攻击骰、效果骰、伤害 / 燃烧 token | 高于棋盘和 HUD，锚定目标附近，不边栏化 |
| 辅助 HUD | 生命 / 法力 / 聚魔、回合结束 | 贴玩家与右下命令，不抢主舞台 |
