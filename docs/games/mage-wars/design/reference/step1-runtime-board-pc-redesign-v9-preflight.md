## 规则到画面映射

| 规则结论 | 影响的画面主体 | v9 设计决策 / 禁止项 |
| --- | --- | --- |
| 学徒模式只用 `2x3` 半场 | 中央竞技场 | 用正式 `standard-arena.jpg` 作为第一视觉主体，并用六个轻量区域高亮呈现学徒半场；不另画抽象棋盘。 |
| 只能施放本回合已计划法术 | 当前施法 + 已计划法术槽 | 火球术从已计划槽抬升；底部只保留法术书入口和 2 个已计划槽，不写手牌。 |
| 弃牌堆是已消耗公开归档 | 双方弃牌堆 | 缩为所属玩家边缘的小牌堆入口，低于当前施法权重；不放中央、不靠近确认按钮、不与当前法术连线。 |
| 隐性结界附属在目标上，展示前隐藏身份 | 宿主旁卡背 | 卡背贴近法师 / 生物 / 区域，显示归属和数量；对手不见正面或卡名。 |
| 施法必须选择合法目标并支付费用 | 当前行动链 | 当前目标在棋盘对象本体高亮；费用和确认 / 取消贴近目标与当前法术，不远离主链。 |
| 攻击骰与 12 面效果骰用于结算 | 目标附近骰盘 | 攻击骰使用正式贴图；效果骰做成有面、有材质、有数字落点的 12 面程序化对象，禁止蓝圆 / 数字气泡。 |
| 法师状态板只作参考来源 | 双方法师 HUD | 生命、法力、聚魔、伤害贴法师牌，用自制运行态 UI；不把状态板图片做成大面板。 |

## 框体职责回执

| UI 承载 | 处理 | 现实职责 |
| --- | --- | --- |
| 棋盘外硬框 | 删除 | 棋盘素材自带边界足够，开放桌面不再包硬框。 |

| 弃牌堆靠近施法链 | 删除 / 移位 | 归档入口不服务当前施法确认；只能贴所属玩家边缘。 |
| 法师状态 HUD | 保留轻量 | 保护生命、伤害、法力、聚魔等动态读数，贴法师牌，不成为整块状态板。 |
| 当前行动槽 | 保留轻量 | 承接选中法术、费用、目标和 `确认 / 取消`，按钮底板只服务点击命中。 |
| 目标高亮 | 保留轻量 | 服务真实区域 / 卡牌对象选择态，不使用代理列表。 |
| 骰盘 | 无底板 | 骰子直接落在目标附近，用阴影、落点和短标签区分。 |
