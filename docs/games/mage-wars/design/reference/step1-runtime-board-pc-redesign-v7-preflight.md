## 规则到画面映射

| 规则结论 | 影响的画面主体 | v7 设计决策 / 禁止项 |
| --- | --- | --- |
| 学徒模式只用标准竞技场一半的 `2x3` | 中央竞技场 | 只显示玩家当前可用的 `2x3` 真实竞技场裁切；禁止另画抽象六格棋盘或恢复完整标准图当完成态。 |
| 法师初始生命 24、法力 10、聚魔 10，状态板只记录轨道 | 双方法师读数 | 生命、伤害、法力、聚魔使用贴近法师牌的自制运行态条和短数字；法师状态板不在主 UI 可见复现。 |
| 行动标记和快速施法标记放在法师牌上 | 法师牌附近 token | 红 / 蓝行动标记与黑色快速施法标记贴近对应法师牌；禁止用普通灰 chip 或文字开关代替。 |
| 施法目标需符合卡牌射程和目标栏，距离只算水平 / 垂直 | 区域高亮和目标对象 | 目标选择必须发生在真实对象 / 区域本体上；合法目标发光，非法对象保留但降噪；禁止代理列表替代棋盘本体点击。 |
| 火球术支付前可取消，支付后进入反制 / 结算 | 当前行动槽 | 当前卡牌、费用预扣、确认与取消必须贴在同一行动链上；按钮只写短标签，不写规则说明句。 |
| 对手可反制，但隐藏结界不泄露身份 | 对手计划 / 隐性结界 | 对手计划和隐性结界只显示正式卡背、数量与归属；禁止公开卡名或正面。 |

## 框体职责回执

| UI 承载 | 是否保留 | 现实职责 |
| --- | --- | --- |
| 棋盘外大矩形框 | 删除 | 棋盘素材自带物理边界已足够；不再用暗框包住竞技场。 |
| 左右大 dashboard 分舱 | 删除 | 对手计划法术、隐性结界和法术书未知内容改为桌面上的真实卡背 / 卡堆，不再放进黑色侧栏。 |
| 法师血蓝面板 | 降级 | 只保留贴法师牌的细条与短数字，服务动态读数；不得成为独立状态板。 |
| 当前行动按钮底 | 保留轻量 | 只保护 `确认 / 取消` 两个真实命令，按钮贴近目标与当前法术。 |
| 目标 / 射程短标签 | 保留轻量 | 服务棋盘本体选择态，只写短状态，不解释规则。 |
| 骰盘底板 | 删除 | 骰子直接落在目标附近的透明桌面层，靠阴影和光效区分。 |

## 禁止替代清单

- 禁止把 Open Design media / imagegen 生图当作本轮出稿方式。
- 禁止用旧 v6 改名、旧运行页截图、旧移动端截图或历史 AI PASS 冒充 v7。
- 禁止把法师状态板整张或裁切铺进主界面。
- 禁止用 CSS 假卡、文字壳、抽象 token、普通 D6、黑色骰盒、长规则说明句替代正式素材。
- 禁止公开对手计划法术、未公开法术书内容或隐性结界正面；禁止称为对手手牌。
- 禁止 PC 稿未通过前进入移动端适配、运行时实现或实现 E2E。
