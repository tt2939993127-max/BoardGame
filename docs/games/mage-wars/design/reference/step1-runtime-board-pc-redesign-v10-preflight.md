## 规则到画面映射

| 规则结论 | 影响的画面主体 | v10 设计决策 / 禁止项 |
| --- | --- | --- |
| 学徒模式只用 `2x3` 半场 | 中央竞技场 | 用正式 `standard-arena.jpg` 作第一视觉主体，半场只用轻量区域高亮；不另画抽象棋盘。 |
| 当前只能施放本回合已计划法术 | 当前施法 + 已计划法术槽 | `火球术` 从己方已计划槽抬升到施法链；不出现规则不存在的“手牌”。 |
| 弃牌堆是已消耗公开归档 | 双方弃牌堆 | 缩为所属玩家边缘小牌堆入口，低于法术书和已计划法术权重；不放中央、不靠近确认按钮。 |
| 施法要宣告合法目标并支付费用 | 当前行动链 | 目标卡和目标区域在棋盘本体高亮；费用石、确认、取消贴近当前法术与目标。 |
| 隐性结界附属目标，展示前隐藏身份 | 宿主附件 | 只在法师 / 对象旁显示卡背和附件归属，不公开对手看不到的卡名。 |
| 攻击骰与 12 面效果骰是结算组件 | 目标附近骰盘 | 攻击骰使用正式贴图；效果骰必须是有切面、材质和数字落点的 12 面程序化对象，禁止蓝圆 / 数字气泡。 |
| 生命 / 法力 / 聚魔是运行态读数 | 法师 HUD | 自制条贴近法师牌，状态板不进入常驻主 UI；读数必须有形状、色彩和对象锚点。 |

## v10 交互权重裁定

| 对象 | 当前施法态权重 | 默认位置 | 展开方式 | 友好性结论 |
| --- | --- | --- | --- | --- |
| 竞技场 | 主舞台 | 中央最大面积 | 常驻 | 当前目标、距离、区域关系发生在棋盘上，第一眼必须看到棋盘。 |
| 当前法术 | 主动作 | 从己方已计划槽抬升 | 当前步骤展开 | 玩家要确认自己正在施放哪张已准备法术。 |
| 当前目标 | 主动作 | 棋盘对象本体 | 对象高亮 | 目标必须直接点对象，不用代理列表。 |
| 费用 / 确认 / 取消 | 主动作 | 当前法术与目标之间 | 当前步骤展开 | 支付前可取消，确认必须贴近当前决策。 |
| 骰盘 | 结算主反馈 | 目标附近 | 投掷 / 结果时展开 | 只在攻击 / 效果结算时提升权重。 |
| 法术书 | 次级私密入口 | 所属玩家边缘 | 计划阶段展开 | 当前施法态只需入口和数量。 |
| 已计划法术 | 次主 | 所属玩家边缘 | 最多 2 槽常驻 | 当前可施放对象，权重高于弃牌堆。 |
| 弃牌堆 | 低权重归档入口 | 所属玩家边缘，靠近法术书但更小 | 点击后 overlay 检视 | 它确实存在，但不是当前主动作；放中央会误导玩家。 |
| 隐性结界 | 情境主 | 宿主旁 | 展示时抬升 | 它跟宿主绑定，不能变成独立牌区。 |

## 框体职责回执

| UI 承载 | 处理 | 现实职责 |
| --- | --- | --- |
| 棋盘外硬框 | 删除 | 棋盘素材自带实体边界；开放桌面不再加容器壳。 |
| 法术书 / 已计划 / 弃牌区大底板 | 删除 | 用真实卡牌叠放和所属玩家边缘位置表达，不用盒中盒。 |
| 弃牌堆中央位置 | 删除 | 当前步骤没有从弃牌堆选择、回收或复活的规则；中央只留当前施法主链。 |
| 当前行动槽 | 保留轻量 | 保护费用、确认、取消三个真实点击对象。 |
| 目标高亮 | 保留轻量 | 目标对象直选，不能由说明文字替代。 |
| 骰盘底板 | 删除 | 骰子直接落在目标附近，用阴影和材质区分。 |
