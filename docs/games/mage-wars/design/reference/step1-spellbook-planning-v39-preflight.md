## 前置硬失败禁止清单

- 不得出现手牌 / hand / opponent-hand。
- 不得把卡面已有费用、射程、目标栏、骰数或效果正文复写成 UI chip。
- 不得把计划 / 浏览态和目标确认态混在同一工作台。
- 不得用一排不可读小卡冒充完整法术书；必须有分类、分页和焦点预览。
- 不得公开对手已计划法术身份。
