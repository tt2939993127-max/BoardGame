# Mage Wars 开放式行动层 v46 出图前硬回执

> 状态：`preflight-ready / open-design-artifact-only / media-generate-forbidden / human-review-not-allowed / implementation-blocked / mobile-blocked`。本轮只重构 Open Design PC 设计稿，不进入真实 Board/UI。

## 本轮裁定

| 用户反馈 | 改法 |
| --- | --- |
| 不显示确认，目标直选执行 | 删除 `执行攻击` 和 `取消选择`按钮；目标本体高亮承担执行入口 |
| 底部不应是封闭面板 | 删除 v45 的大圆角工作台底板，底部改为开放式叠层，只保留卡牌本体、短标签、分页控件和极弱桌面光影 |
| 节省空间 | 竞技场扩大到 `1320x692`，底部对象贴边并不侵入 A3 / B3 场上卡 |

## 规则到画面

| 规则结论 | 画面主体 | 设计决策 |
| --- | --- | --- |
| 学徒竞技场是 `2x3` 六区域 | 竞技场 / 场上卡 | 六区为第一视觉，场上卡保持唯一 `data-zone-id` |
| 行动由来源对象和合法目标驱动 | 来源卡 / 目标高亮 | 当前来源大卡、棋盘目标和路径线同屏；目标本体承接执行 |
| 法术书和已计划法术仍影响决策 | 开放式底部叠层 | 当前来源、已计划法术、法术书浏览器保持可见可恢复 |
| 对手隐藏信息不能泄露 | 对手已计划法术 | 只显示卡背和数量 |
| 目标确认态不是结算态 | 骰子 / 伤害 | 不提前显示骰子、伤害、燃烧或治疗结果 |
