## 规则到画面结论

| 规则 / 方法论结论 | 画面主体 | 设计决策 / 禁止项 |
| --- | --- | --- |
| 地图 / 棋盘是最低层承载，不是不可覆盖前景 | 竞技场底图 | 拆成必须保护的规则热区与可覆盖低权重石砖区；禁止为了露出整张底图牺牲法术书 |
| 当前玩家需要持续比较法术书候选 | 法术书浏览器 | 保持 10 张 / 页，但上移进入竞技场下沿低权重纹理区，卡牌增至 `104x147` |
| 场上实体和目标必须保护 | A3 / B3 场上卡、B2 目标、骰子、token | 法术书 overlay 不得压实体卡、目标高亮、骰子或 token |
| 已计划法术属于回合推进操作带 | 已计划区、回合结束 | 已计划区继续贴近右下回合结束上方，不和法术书互相挤压 |
| 选中态不是新实体 | 法术书当前焦点、已计划来源 | 只用描边、阴影、轻微抬升和短标签，不生成左右特大牌 |

## v59 出图硬禁止

- 禁止把整张竞技场底图当作不可覆盖矩形。
- 禁止法术书只贴在屏幕底缝或角落，导致卡牌难读、难点、难比较。
- 禁止法术书覆盖 A3 / B3 场上卡、B2 目标、骰子、伤害 / 燃烧 token 或区域归属。
- 禁止通过左右特大牌、第二卡面、第二工作台表达选中 / 焦点 / 来源态。
- 禁止删除骰子、效果骰、伤害 token、燃烧 token、守卫 token、行动 / 快速施法 token、法术书、已计划法术、弃牌堆和对手已计划卡背。
- 禁止出现规则不存在的 `手牌`，以及常驻 `确认 / 执行 / 取消`。
