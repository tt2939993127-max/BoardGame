# 法师战争 Step 1 PC Open Design v14 出图前硬回执

> 状态：`preflight-ready / open-design-artifact-route / media-generate-forbidden / human-review-not-allowed`。v14 专门修复 v13 右下骰盘压住场上卡牌的问题。

## 继承的规则前提

- 当前主链仍限定为：竞技场、当前施放法术、目标、费用、确认 / 取消、攻击骰和 12 面效果骰。
- 法术书、已计划法术和弃牌堆仍属于所属玩家边缘牌区；弃牌堆是低权重公开归档入口，不进入中央。
- 场上生物 / 魔物 / 目标卡牌是正式卡图主体；结算骰盘和伤害 token 只能贴近结果，不能压住卡面或互相堆叠。

## v14 修正点

| v13 失败点 | v14 处理 |
| --- | --- |
| 攻击骰 / 效果骰压住右下场上卡牌 | 将骰盘移到右侧独立结算槽，放在对方侧牌区下方、确认区上方，不侵入竞技场卡面。 |
| 伤害 token 贴在目标卡面右下角，容易误读成压卡 | 将伤害 token 锚到目标卡外侧右边缘，保持归属但不遮挡卡面主体。 |
| 旧几何检查漏掉骰盘与场上卡牌碰撞 | v14 检查扩展为骰盘 / 伤害 token 对场上卡牌、状态 token、牌区、确认区、法师 HUD 的碰撞。 |
