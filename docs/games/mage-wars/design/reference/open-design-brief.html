结构合同

中央竞技场

使用标准竞技场素材，叠加区域热区、对象层和 FX 层；区域选择必须点对象本体。

玩家状态

生命、伤害、法力、聚魔、行动/快速施法标记贴近各自法师，不做远离棋盘的统计墙。

法术书与已计划法术

自己的法术书入口、最多两张已计划法术和弃牌堆在底部固定槽；对手只看卡背或数量，不泄露身份。

法术 FX 合同

阶段表现来源
起手施法者、魔宠或再生点发光 / 符文圈已验证施法事件
目标锁定目标区域、生物、墙体或宿主高亮目标解析事件
路径/扩散火球、治疗、推斥、召唤、结界展示的运动轨迹结算事件
命中伤害、治疗、状态、召唤或翻开结界的落点反馈reduce 后状态变化

禁止项

  • 不把 TTS 桌面当最终视觉风格。
  • 不把已有卡图、token 图替换成文字壳。
  • 不在常驻主 UI 写规则解释正文。
  • 不让失败命令播放成功法术特效。
  • 不因为 Open Design artifact 存在就跳过真实页面截图验收。
