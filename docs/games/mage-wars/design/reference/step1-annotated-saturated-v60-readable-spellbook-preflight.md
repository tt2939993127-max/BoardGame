## 用户问题裁定

| 用户问题 | 裁定 |
| --- | --- |
| 下面的阴影是什么意思 | v59 阴影只是为了托住法术书可读性的视觉补丁，没有规则对象、材质、交互热区或状态反馈职责；必须删除或改成有明确语义的法术书页 / 桌沿材质 |
| 法术书候选为什么还是小 | v59 为保留 `10 / 页` 把候选压成 `104x147`，这是容量优先，不是玩家可读性优先 |
| 有没有设计标准 | v60 采用明确标准：PC `1920x1080` 常驻法术书候选卡不低于约 `120x169`，若 10 张放不下则改为 8 张 / 页；完整读卡由 hover / inspect 临时层负责，但常驻候选至少要可辨卡名、主图和费用角区 |

## 方法论到画面结论

| 方法论 / 规则 | 画面主体 | v60 设计决策 |
| --- | --- | --- |
| UCD：玩家目标优先，不为布局牺牲任务 | 法术书候选 | 当前玩家需要比较可支配法术，候选卡必须可读；宁可分页更多，也不硬塞十张小牌 |
| Hick：大集合用分类和分页降低决策负担 | 法术书 30 张 | 保留分类签和分页；一页显示 8 张，页码改 `1 / 4`，容量显示 `法术书 30 / 8 / 页` |
| Fitts：常用目标要足够大、距离短 | 法术书候选、分页 | 候选卡放大到 `120x169`；分页贴在法术书页侧边，按钮不小于 `42x42` |
| 黄金比例：卡牌本体比例应稳定 | 法术书卡牌 | 保持真实卡牌约 `1:1.41` 视觉比例；常驻候选不升级成 v56 式 `260x366` 大卡 |
| 视觉引导：提示要贴合交互对象 | 选中 / 来源态 | 只用完整卡边高亮、轻抬升和短状态贴附；不新增第二实体或外部字段复写 |
| 视觉垫层必须有语义职责 | 法术书底部承载 | 删除 v59 无语义黑影；改为开放式法术书页 / 旧纸托盘材质，职责是“承载可浏览法术书页”和“可读遮罩” |

## 尺寸与分页标准

| 对象 | v59 | v60 标准 |
| --- | ---: | ---: |
| 法术书候选卡 | `104x147` | `120x169` |
| 单页候选数 | `10` | `8` |
| 分页 | `1 / 3` | `1 / 4` |
| 容量文案 | `法术书 30 / 10 / 页` | `法术书 30 / 8 / 页` |
| 选中态 | `translateY(-9px)` | 不改变占位；允许 `translateY(-10px)` 和描边，但不得改变卡尺寸 |
| 完整读卡 | 未在常驻主态展开 | hover / focus / inspect 临时层；不占常驻布局，不遮挡当前目标 |

## 规则对象守恒

| 规则对象 | v60 默认可见性 | 禁止项 |
| --- | --- | --- |
| 法术书候选 | 当前页 8 张正式卡图可见，分类和分页可见 | 禁止称为手牌；禁止小牌墙；禁止卡外复写费用 / 射程 / 目标字段 |
| 已计划法术 | 右下回合结束上方，2 张正式卡图可见，来源用贴附短状态 | 禁止复制一张“已选法术”；禁止确认 / 执行 / 取消常驻按钮 |
| 弃牌堆 | 归档入口，卡背堆 + 数量 | 禁止正面顶牌常驻展示；禁止抢主焦点 |
| 对手已计划法术 | 左上镜像，卡背 + 数量 | 禁止公开卡名或正面 |
| 竞技场 / 区域 | 2x3 区域仍是空间主体 | 法术书可覆盖低权重石砖，但不得遮挡场上实体、目标、骰子、token 或区域归属 |
| 骰子 / token | 当前结算浮层，锚在 B2 目标附近 | 禁止省略；禁止边栏化；禁止被法术书压住 |

## v60 出图硬禁止

- 禁止无语义黑影、暗角、玻璃壳或大色块托住法术书。
- 禁止为了保留 `10 / 页` 把法术书候选卡压到不可读。
- 禁止把法术书候选叫“手牌”。
- 禁止法术书覆盖 A3 / B3 场上卡、B2 目标、骰子、伤害 / 燃烧 token 或区域归属。
- 禁止通过左右特大牌、第二卡面、第二工作台表达选中 / 焦点 / 来源态。
- 禁止删除骰子、效果骰、伤害 token、燃烧 token、守卫 token、行动 / 快速施法 token、法术书、已计划法术、弃牌堆和对手已计划卡背。
- 禁止出现常驻 `确认 / 执行 / 取消`；当前状态仍是选来源 / 点目标的开放式直选链路。

## v60 AI 核验门

- 图片加载必须全部成功。
- 法术书必须显示 `法术书 30`、`8 / 页`、`1 / 4`，且当前页 8 张候选卡。
- 法术书候选卡必须接近 `120x169`，选中不改变常驻占位。
- 法术书页可以覆盖竞技场低权重纹理区，但承载材质必须像法术书页 / 旧纸托盘，不得是无语义黑影。
- 法术书不得与场上实体、目标、骰子、已计划区、回合结束、弃牌堆重叠。
