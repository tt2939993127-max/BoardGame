# 法师战争 Step 1 PC Open Design v17 出图前硬回执

> 状态：`preflight-ready / open-design-artifact-route / media-generate-forbidden / human-review-not-allowed-until-ai-pass`。v17 专门修复 v15 / v16 被指出的 UI 重叠、贴边和重复焦点。

## 继承的规则前提

- 当前主链仍限定为：竞技场、当前施放法术、目标、费用、确认 / 取消、攻击骰和 12 面效果骰。
- 法术书、已计划法术和弃牌堆属于所属玩家边缘牌区；弃牌堆是公开归档入口，不进入中央舞台。
- 对手已计划法术、未公开法术书内容和隐性结界只显示卡背 / 数量，不泄露正面或卡名。
- 生命、法力、聚魔继续作为 `approved-programmatic-runtime-ui`，贴近法师 HUD 表达；不复现整张法师状态板。

## v17 修正点

| v16 失败点 | v17 处理 |
| --- | --- |
| 独立火球术大卡贴底且和已计划槽重复 | 移除独立贴底大卡，把火球术作为真实卡面放入已计划槽并加轻量当前态 |
| 聚魔 token 像压在 HUD / 法师牌上 | 移除盖压 token，保留 HUD 中的聚魔数值和蓝条 |
