## 本轮修正点与失败点

- 删除卡外可见卡名 / 费用 / 射程 / 目标字段复写；卡名只保留在卡图本体和 `alt / aria-label` 无障碍文本中。
- 法术书改成焦点大卡 + 邻近候选：焦点卡 `260x366` 虽然承担读卡，但作为常驻对象过大，破坏法术书候选、场上卡和棋盘的牌桌比例。
- 已计划法术改成当前来源大卡 + 次卡槽位：当前来源卡 `260x366` 虽然可读，但不应以常驻大卡压住主牌桌视觉；完整阅读应交给 hover / focus / inspect 临时层。
- 弃牌堆降权为卡背堆 + 数量入口，不展示正面顶牌，也不压住已计划牌或当前来源牌。
- 保留攻击骰、效果骰、伤害 token、燃烧 token、守卫 token、行动 / 快速施法 token；没有为“干净”减少用户点名物理件。

## 撤销原因与下一版门禁

- `AI_PASS` 已撤销；v56 不允许进入人工验收。
- 下一版必须先写卡牌游戏比例预算：棋盘 / 场上卡 / 法术书候选 / 已计划来源 / 临时 inspect 层各有尺寸上限。
- 读卡策略必须是常驻可辨认、hover / focus / inspect 临时放大；不能把检视层尺寸常驻到牌桌层。
- 用户未明确批准前，仍禁止 Board/UI 实现、真实运行页 E2E 和移动端适配。
- 本稿只覆盖 PC 桌面饱和主态；移动端必须等 PC 人工批准后再做。
