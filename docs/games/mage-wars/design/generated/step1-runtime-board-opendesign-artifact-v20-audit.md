| 细节 | 批判 | 裁定 |

## 收口结论

- 规则已经提炼成可执行 UI 规则：Mage Wars 学徒图必须先成立 `2x3` 六区域，卡牌必须唯一归属区域，token 必须贴附宿主，攻击骰 / 效果骰必须贴近当前目标或来源链路。
- 卡牌不能摆在两个区域中间；这不是视觉偏好，而是移动、射程、近战目标和状态归属的规则前提。
- 可以学习召唤师战争的“格子先行、对象在格内、点击对象本体”交互不变量；不能学习它的皮肤、牌区名称或手牌语义。
- v20 可作为当前 PC Open Design 人工验收候选；用户明确批准前，仍禁止进入真实 Board/UI 实现、真实页面 E2E 或移动端适配。
