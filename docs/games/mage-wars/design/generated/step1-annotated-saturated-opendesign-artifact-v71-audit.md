# Mage Wars Open Design v71 AI 图面核验

> 结论：`AI_PASS / human-review-allowed-in-chat / map-bottom-layer-overlay-fixed / implementation-blocked-until-user-approval / mobile-blocked-until-pc-approval`。本稿是 Open Design artifact 渲染截图，不是图片模型生图；未调用 `od media generate`。v71 专门回应用户指出的 `为什么还在躲着地图`：v70 把法术书放成地图外底栏，v71 改为竞技场底图最低层承载，法术书作为开放 overlay 覆盖竞技场下缘低权重石砖区。

## v70 撤销原因

| 项 | 裁决 |
| --- | --- |
| v70 几何结论 | 不重叠、底部空隙小、分页 / 计划区分离，这些只能证明工程摆放没有压叠。 |
| v70 玩家视角失败 | 法术书仍贴在屏幕底部控制基线上，视觉语义像地图外底栏，说明整张地图仍被当作不可覆盖排斥体。 |
| 当前修正原则 | 地图 / 竞技场底图是最低层；只保护格线语义、场上卡、骰子、token、关键读数和已计划来源，不保护低权重石砖纹理。 |

## 用户原话自审

| 用户原话 / 意图 | v71 自审 |
| --- | --- |
| `为什么还在躲着地图` | PASS。法术书卡面整体上移，卡面联合区域 `y=815-1015`，与原始 2x3 竞技场网格 `y=30-880` 有 `65px` 垂直重叠；它现在压在竞技场下缘石砖层上，不是地图外底栏。 |
| `地图是最下层，不要被底图支配` | PASS。`.arena` 底层从 `850px` 延展到 `1030px`，让法术书后方仍是同源竞技场石砖；网格线只在真实 2x3 区域保留，避免把延展底层误读成新规则格。 |
| `开放式设计 / 场地直选优先` | PASS。没有新增代理目标面板、问号块或确认按钮；场上目标仍由 B2 西锁骑士本体高亮承接。 |
| `标签放左侧` | PASS。分类标签仍在法术书左侧，不压己方法师状态区。 |
| `分页按钮就保持原样啊` | PASS。右侧 `42x42` 页角式上 / 下分页按钮保持 v65 样式和贴近法术书的位置；页码仍只是中间附属读数。 |
| `骰子、token 都被你省略掉了` | PASS。攻击骰、效果骰、伤害 token、燃烧 token 仍在目标附近上层显示，没有降级到边栏或删除。 |
| `别显示确认了` | PASS。没有常驻确认 / 执行 / 取消控件；选中来源与合法目标通过高亮和短状态承接。 |
| `弃牌堆是给人看的吗` | PASS。弃牌堆仍是右下紧凑归档入口，只显示数量和卡背堆叠，不展示正面大卡。 |

## 本轮修正点

| 对象 | v70 问题 | v71 修正 |
| --- | --- | --- |
| 竞技场底层 | 竞技场视觉高度停在 `850px`，法术书下方像脱离地图的底栏 | 竞技场底层延展到 `1030px`，作为法术书后方的低权重石砖承载层 |
| 法术书牌列 | `top=808`，卡面主要落在原始竞技场外 | `top=748`，卡面与原始竞技场网格下缘重叠 `65px` |
| 规则热区 | 不能为了覆盖地图压到场上实体 | 几何确认法术书卡面不压场上四张卡、骰子 / token、计划区、弃牌堆或回合结束 |
| 网格语义 | 延展底图容易被误读成更多区域 | 网格线只覆盖真实 2x3 竞技场区域，延展区只承担石砖底层和开放 overlay 背景 |
