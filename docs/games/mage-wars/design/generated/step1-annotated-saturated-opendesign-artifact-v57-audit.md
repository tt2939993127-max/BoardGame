# Mage Wars Open Design v57 AI 图面核验（已撤销）

> 结论：`AI_PASS_REVOKED / REVISE / spellbook-page-density-failed / prepared-zone-placement-failed / selected-state-layout-stability-failed / human-review-blocked / implementation-blocked / mobile-blocked`。本稿是 Open Design artifact 渲染截图，不是图片模型生图；未调用 `od media generate`。此前 `AI_PASS` 只证明 v56 的无限放大问题有所收敛，但用户复核后指出三项硬失败：法术书真实容量是 30/33 张而不是一页 4 张候选；已计划牌应归到回合结束操作区上方；左右特大牌让选中 / 来源态改变常驻布局占位，违反“选中态不得改变常驻布局占位”规则。

## 撤销原因

- **法术书容量失败**：学徒法术书合同锁定兽王 33 张、女祭司 / 邪术师 / 巫师各 30 张；v57 一页只显示 4 张，并标 `1 / 5`，不能代表真实浏览密度。
- **已计划区落位失败**：已计划法术最多 2 张，语义上属于当前行动 / 结束回合附近的操作对象；v57 仍把它作为右下大牌区，挤压主画面而没有贴近回合结束按钮。
- **选中态布局稳定性失败**：v57 的法术书焦点牌和已计划来源牌变成左右两张特大牌，视觉上像新实体 / 新主舞台；选中、焦点或来源状态应使用同尺寸高亮、短状态贴附或临时 inspect 层，不得常驻改变牌列和操作区布局。
- **人工验收冻结**：v57 不再允许人工验收，也不得作为实现、移动端或真实页面 E2E 的依据。

- 撤销 v56 旧 `AI_PASS`：`260x366` 常驻焦点卡 / 来源卡被判定为 `card-scale-ratio-failed`。
