# Mage Wars Open Design v75 AI 图面核验

> 结论：`AI_PASS / human-review-allowed-in-chat / discard-public-face-up / implementation-blocked-until-user-approval / mobile-blocked-until-pc-approval`。本稿是 Open Design artifact 渲染截图，不是图片模型生图；未调用 `od media generate`。v75 专门修正 v74 的规则语义错误：弃牌堆是公开归档，不是隐藏信息，因此紧凑入口显示顶牌正面 / 半露正面 + 数量。

## 用户原话自审

| 用户原话 / 意图 | v75 自审 |
| --- | --- |
| `规则上弃牌堆是不能看的？那为什么存在在，如果能看，为什么不显示正面` | PASS。规则与设计合同均裁定弃牌堆可检视公开内容；v74 用卡背是把“低权重归档”误做成“隐藏信息”，v75 已改为公开顶牌正面。 |
| `弃牌堆放这里就差不多了` | PASS。位置仍在用户标注的右侧竖向空位，对手状态区下方、己方已计划法术区上方。 |
| `你是不理解现在的弃牌堆是小过头了吗` | PASS。仍沿用 v74 数据口径：弃牌堆顶牌约 `71x98`，为计划牌高度 `224` 的 `43.8%`，不再像微型图标。 |
| `手牌改6张，要放大一点` | PASS。按规则术语落为法术书牌列；仍是 6 张，单张 `158x224`。 |
| `计划牌大小和手牌一致` | PASS。两张已计划法术仍为 `158x224`，与法术书卡面同尺寸。 |
| `分页按钮就保持原样啊` | PASS。分页 rail、按钮样式和 `1 / 5` 读数未改。 |
| `骰子、token 都被你省略掉了` | PASS。攻击骰、效果骰、伤害 token、燃烧 token 均保留在当前目标附近。 |

## 规则裁定

| 对象 | 规则 / 设计结论 | 图面表达 |
| --- | --- | --- |
| 公开弃牌堆 | 可检视公开内容，不属于隐藏信息 | 右侧归档入口显示顶牌正面 / 半露正面 + `弃牌 3` |
| 对手已计划法术 | 隐藏信息 | 左上只显示 2 张卡背和数量 |
| 未公开法术书内容 | 隐藏 / 私密集合 | 当前稿不展开对手法术书 |
| 隐性结界 | 隐藏信息 | 仍按卡背 / 数量 / 宿主附件处理，不公开身份 |

## 几何证据

| 检查项 | 结果 |

| 法术书当前页卡数 | `6` 张 |
| 已计划法术卡数 | `2` 张 |
| 法术书卡面尺寸 | `158x224` |
| 已计划法术卡面尺寸 | 两张均为 `158x224` |

| 弃牌堆顶牌 | 正面卡 `71x98`，相当于计划牌高度 `43.8%` |
| 弃牌堆压叠 | `0`：不压对手状态、计划牌、回合结束、场上卡、骰子或 token |

## 玩家视角核验

| 维度 | 评分 | 结论 |
| --- | ---: | --- |
| 任务清晰度 | 19 / 20 | 弃牌堆现在能被理解为公开归档入口，不再像隐藏未知牌 |
| 视觉层级 | 14 / 15 | 顶牌正面可辨，但尺寸和位置仍低于计划牌、法术书和当前目标 |
| 对象可识别性 | 15 / 15 | 卡牌、卡背、骰子、token、法师牌和竞技场均使用真实素材 |
| 状态与动作载体 | 14 / 15 | 归档入口只承载数量与公开顶牌，没有伪装成当前可执行来源 |
| 布局完整性 | 14 / 15 | 主要槽位无压叠；弃牌堆仍落在用户标注右侧空位 |
| 素材完整性 | 10 / 10 | 未见破图、空占位、普通蓝圆效果骰或低质 token 替代 |
| 操作人体工学 | 9 / 10 | 法术书、分页、计划牌、弃牌堆和回合结束各自贴近职责区，没有双主焦点 |

总分：`95 / 100`。硬失败项：无。
