| 攻击骰 | PASS | v11 从正式 `attack-die-texture.png` 裁出骰面图，不再是 v10 的红黑块或通用数字骰。 |

| 问题 | 影响 | 处理 |

## 仍需人工判断

- 这版已经满足“可送人工验收”的最低线，但是否作为最终美术方向仍由用户决定。
- 若用户要求继续提升质感，下一轮优先打磨法师 HUD 与卡牌尺度关系，而不是改变弃牌堆规则位置。
- PC 桌面稿未获用户明确批准前，仍冻结实现、移动端和真实运行页验收。
