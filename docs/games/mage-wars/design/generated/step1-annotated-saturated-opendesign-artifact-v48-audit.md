## 撤销原因

| 用户反馈 | 现实问题 | v49 修正方向 |
| --- | --- | --- |
| “已计划和已选法术为什么要重复” | 同一张已计划 `火球术` 同时显示在右下已计划槽和底部“已选法术”大卡里，会让玩家误以为场上存在两张实体牌，违反“同一规则对象只由一个物理主体承接”的设计口径 | 删除底部“已选法术”复制卡；右下已计划槽中的 `火球术` 本体放大并标记为当前来源；法术书列表不再重复显示已计划的 `火球术` |

## 规范引用验收矩阵

| 设计规范条款 | v48 图面证据 | 结论 |
| --- | --- | --- |
| `对手计划必须按席位镜像`、`对手已计划法术区` | 对手已计划法术位于左上，显示 2 张卡背和数量；未公开牌名 | 符合 |
| `问号区只保留规则职责` | 左下大玩家区已删除；法师状态由法师牌 + 血条 / 蓝条 / 聚魔承接；右下计划区收缩为 2 张已计划槽；关系箭头删除 | 符合 |
| `分页样式继承用户标注` | 法术书分页为贴近书页底部的 `page-corner prev / next` 页角控件，不再是漂浮圆按钮 | 符合 |
| `直接执行 / 撤选` | 常驻确认 / 执行 / 取消控件数量 `0`；目标本体和目标高亮承接提交语义 | 符合 |
| `攻击 / 治疗需要骰子结算`、`用户标注 / 参考图元素守恒` | 攻击骰、效果骰、伤害 token、燃烧 token、行动标记、快速施法标记、守卫 token 均出现在主图中 | 符合 |

| `空间预算`、`场上卡必须保留唯一 zoneId 和可见区域归属` | 场上卡中心均落在 `A2 / A3 / B2 / B3` 对应区域，西锁骑士为 B2 目标，火烙魔婴只作为普通 A3 场上生物 | 符合 |
