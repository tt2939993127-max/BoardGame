# Mage Wars 标注图饱和布局 v50 AI 图面核验撤销记录

> 结论：`AI_PASS_REVOKED / REVISE / human-review-blocked / implementation-blocked / mobile-blocked / superseded-by-v51-required`。v50 的旧几何结论只证明没有明显重叠和实体重复，不能证明玩家视角通过；用户指出其仍以代理 UI 替代真实对象直选后，本稿不得再进入人工验收。

## 撤销原因

| 失败项 | 现实问题 | v51 修正方向 |
| --- | --- | --- |
| `open-direct-selection-failed` | B2 场上 `西锁骑士` 本体已经可见并能直选，但 v50 仍放了目标摘要块和大箭头，迫使玩家读代理 UI | 删除目标摘要块和大箭头，B2 本体高亮承接目标点击 |
| `proxy-target-summary-failed` | 目标摘要虽然没有复制卡图，但仍把真实目标选择变成第二个阅读区 | 只保留场上卡高亮和极短状态，目标信息由 B2 卡本体承担 |
| `discard-pile-overexposed` | 弃牌堆是公开归档入口，不是当前主动作对象；展示正面顶牌会误导玩家以为当前要看或选择它 | 弃牌堆降为小卡背堆叠 + 数量 |
| `dead-space-and-agent-ui-failed` | 中下部空白和问号式代理区没有规则职责，没有把空间交还给法术书分页或当前动作链 | 空白改为法术书分页职责，不能留无职责 UI |
| `player-workflow-failed` | 玩家理论上可以直接看 B2 高亮，但画面仍通过路径线、摘要和入口重复解释，增加无效步骤 | 当前来源只贴短状态，合法目标只高亮本体 |

以下旧评分保留为历史记录，不再作为通过依据。

## 阶段边界

- 允许：把 v50 原图打开给用户做人工作图验收。

- 后续：若用户指出图面仍不通过，v50 立即降级为 `REVISE`，下一轮先回到同一实体锚点规则和玩家任务链重构。
