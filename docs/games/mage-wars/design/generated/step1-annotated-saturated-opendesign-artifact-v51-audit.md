| 失败项 | 用户可见后果 | v52 修正方向 |

| `bottom-map-layer-misread` | 把竞技场底图当成必须完整避让的前景主体，导致中间低权重石砖纹理被过度保护 | 明确竞技场底图是最低层承载；只保护格子语义、区域标签、场上卡、目标高亮、骰子和 token |

## 负向影响检查

| 调整 | 可能负面影响 | 当前承载 |
| --- | --- | --- |
| 删除目标摘要块 | 玩家可能找不到目标名 | B2 场上 `西锁骑士` 本体可读，贴 `可选` 短状态和目标高亮 |
| 删除大箭头 | 玩家可能看不出来源到目标关系 | 当前是目标选择态，不是流程说明态；来源由右下 `火球术` 徽标承担，目标由 B2 高亮承担 |
| 弃牌堆删除正面顶牌 | 玩家可能不知道弃牌堆存在 | 右下仍有小卡背堆叠和 `弃牌 3` 数量，可作为公开归档入口 |
| 中下空白改为分页 | 分页可能显得独立 | 分页紧邻法术书候选右侧，用户标注图要求的上下切换语义已经可见 |

## 阶段边界

- 允许：把 v51 原图打开给用户做人工作图验收。
- 禁止：在用户批准前实现真实 Board/UI、启动真实运行页、跑实现 E2E 或开始移动端适配。
- 后续：若用户指出图面仍不通过，v51 立即降级为 `REVISE`，下一轮必须继续按“真实对象直选 + 归档降权 + 少代理 UI”重构。
