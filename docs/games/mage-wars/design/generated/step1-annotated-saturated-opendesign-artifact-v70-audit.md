## 本轮修正点

| 对象 | v66/v67/v68/v69 问题 | v70 修正 |
| --- | --- | --- |
| 法术书牌列 | 底边仍有无职责暗带；前几版为避让其它控件又把牌列抬高 | 将法术书浏览器下压到 `top=808`，牌底距屏幕底边 `13px`，底边空间不再空置 |
| 已计划法术 | 右下被分页、弃牌和回合结束挤成附属物；来源标签曾压标题 | 独立右侧计划槽，卡面 `96x136`，来源标签贴入卡面右上，不压标题 |
| 分类标签 | v67 曾压近己方状态区 | v70 保持左侧书签，但几何确认不与己方状态区相交 |
| 分页 rail | v67 曾与计划区相交 | v70 保持原样侧边按钮，同时与计划区、最后一张法术书卡分离 |
