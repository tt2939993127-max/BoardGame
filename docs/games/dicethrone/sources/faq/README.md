## 使用口径

- FAQ 是规则裁定参考，不替代角色图面真相源；若 FAQ、玩家板/卡图、官方规则书互相冲突，必须在对应角色核对文档里记录冲突并请用户拍板。
- 新角色 intake 时，完成静态录入后应按本 FAQ 扫描该角色相关常见问题，尤其是“可先花费/可被打断/攻击是否成立/状态是否移除/防御是否仍可用”这类时序规则。
- 测试通过只能证明覆盖到的 FAQ 条目；不得把某个角色的代表性测试外推成整份 FAQ 已实现。
