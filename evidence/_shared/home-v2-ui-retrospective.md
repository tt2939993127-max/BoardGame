# Home V2 UI 误改复盘

日期：2026-04-06

## 对照基线

- 基线截图来源：`D:\gongzuo\webgame\BoardGame-wt-home-v2\test-results\home-v2-local-mobile.png`
- 固定对照副本：`D:\gongzuo\webgame\BoardGame-wt-home-v2\test-results\baselines\home-v2-first-version-mobile-baseline.png`
- 真参考图：`D:\gongzuo\webgame\BoardGame-wt-home-v2\test-results\baselines\参考图.png`
- 打包版参考：`D:\gongzuo\webgame\BoardGame-wt-home-v2\test-results\baselines\home-v2-packaged-desktop-reference.png`

这张基线图保留了“第一版可接受状态”的几个关键事实：

- 书本壳完整、稳定，左右页关系清楚。
- 左页 4 张卡虽然不够精致，但信息关系简单，没有额外装饰干扰。
- 右页留白，整体仍然像“游戏首页壳体”，而不是工具台。

这张真参考图额外明确了两条之前没有说透的规则：

- 边框只包裹图片，不包标题和说明文字。
- 布局重点是“页内规则排布”，不是把单张卡片本身做得更重、更花。

## 从真参考图提炼出的硬规则

1. 图片是主体，边框只是图片容器的装饰线。
2. 标题必须脱离边框，单独放在图片下方，不得再塞进 holder 底部。
3. 卡片/条目之间靠整页排布建立秩序，不靠每张卡自己的厚重皮肤建立秩序。
4. 页内应该优先追求“均匀、成行成列、留白稳定”，而不是给单卡加重阴影、胶囊底、外发光。
5. 如果缩略图资源不稳定，边框更要轻，因为重边框只会把白块和破图放大。

## 这次为什么改错

### 1. 把“像游戏一样、对标炉石”误读成了“增加装饰感”

用户真正要的是：

- 首页像游戏首页
- 主次关系更清楚
- 保留当前书本壳的整体观感

我错误地把它翻译成了：

- 给卡片加更多质感
- 给标题加胶囊底
- 给详情页按钮和面板加更重的视觉处理

结果是装饰变多了，但信息层级并没有更清楚，反而更花。

### 2. 没守住“先对照第一版，再做增量”

这轮正确做法应该是：

- 先拿第一版截图当基线
- 只改 1 到 2 个最核心变量
  - 例如卡片密度
  - 或书本舞台垂直位置
- 每改一次就和基线图对照

我实际做成了：

- 同时改卡片样式
- 同时改详情页样式
- 同时改 scene 区域
- 同时改书本舞台位置
- 同时补新 E2E

变量过多，导致一旦变丑，很难第一时间知道到底是哪一步搞坏的。

### 3. 把“表现问题”做成了“组件重画”

当前首页真正的问题更接近：

- 卡片密度
- 书页利用率
- 上下留白
- 首页主入口的聚焦感

而不是：

- 卡片本身缺一套新皮肤
- 标题缺胶囊底
- 房间区缺更重的材质感

我改成了重画组件外观，等于把“表现收口”做成了“重新设计卡片”，方向跑偏了。

### 4. 忽略了缩略图当前是缺失态，任何重装饰都会把问题放大

现阶段 E2E / 本地截图里，部分缩略图本来就有白块/缺图状态。

第一版里，这个问题虽然存在，但因为卡片比较克制，还没有被过度放大。

我后来加了：

- 更明显的卡框
- 更亮的标题底
- 更重的 hover / 阴影语言

结果白块缩略图显得更突兀，整体观感就更丑。

### 5. 不该顺手动详情页

这轮反馈核心是首页 UI。

我却顺手把：

- 详情页返回按钮
- 房间面板
- 创建房间按钮

也一起改了，扩大了修改面。这既增加了判断噪音，也让“首页到底有没有变好”更难看出来。

## 后续约束

后面再改 home-v2 UI，必须遵守：

1. 每一轮先对照 `test-results/baselines/home-v2-first-version-mobile-baseline.png`
2. 单轮只允许收 1 个主问题
3. 首页问题只改首页，不顺手改详情页
4. 缩略图未稳定前，不给卡片加重装饰
5. 若要改 scene 几何和卡片样式，必须分两轮做，不能一轮混改
6. 后续改首页卡片时，默认禁止再改成“边框包住图片+标题”的一体式卡片；除非用户明确要求推翻真参考图。

## 下一轮正确切入点

如果继续推进，最正确的切入点不是“重新设计卡片”，而是：

- 先只校准书本舞台和 left page 内容区的位置关系
- 再只调 4 张卡在左页里的密度与间距
- 保持边框只包图片，标题放在图片下方；优先收布局，不重画皮肤
