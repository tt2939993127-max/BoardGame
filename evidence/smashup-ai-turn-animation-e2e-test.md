# SmashUp AI / 他人回合中间停留动画回归证据

## 范围

- 目标问题：大杀四方中，AI 或其他玩家出牌后，视觉上像“随从/回合动画卡在屏幕中间几秒”。
- 本轮改动：
  - 清理运行时与测试热路径上的高频 `console.log`，减少主线程阻塞。
  - 将“大杀四方轮到你了”提示从屏幕正中改到顶部，并把停留时间从 `3000ms` 缩短到 `1200ms`。

## 执行命令

```bash
npm run test:e2e:ci:file -- e2e/smashup-local-gameplay.e2e.ts "本地模式：出牌 → 结束回合 → 回合切换"
```

## 结论

- 结合代码排查，本轮更像是两个问题叠加：
  - 热路径日志过多，导致事件流与渲染链在开发环境下明显变慢。
  - 回合切回我方时，原本 `3s` 的居中 `your_turn` 提示会直接占据屏幕中间，主观上很像“动画卡住”。
- 这轮回归命令已通过，且截图中未再出现居中长时间停留的覆盖层。

## 未覆盖风险

- 当前证据来自本地模式“出牌 → 结束回合 → 回合切换”链路，不是在线房间里“隐藏手牌的其他玩家出牌”那条链路。
- 如果你反馈的是在线多人里“对手隐藏手牌出牌时，仍有牌体从中间停留”，那还需要再补一条在线 AI / 对手视角的专门截图链路继续核实。
