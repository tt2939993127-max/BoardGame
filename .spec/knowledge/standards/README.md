# BoardGame 项目标准

这里是项目 AI 标准的唯一正文目录。不要从文件名猜测读取范围，先从上一级 [知识导航](../README.md) 按任务场景进入。

标准按职责分组：

- 规则与引擎：`engine-*.md`、`rule-contract-audit.md`、`description-to-implementation-audit.md`、`undo-auto-advance.md`。
- UI 与交付：`ui-*.md`、`e2e-verification.md`、`generated-design-implementation.md`、`home-v2-design.md`。
- 审计与回归：`testing-audit*.md`、`audit-evidence-template.md`、`regression-closeout.md`、`shared-refactor-guard.md`。
- 资源与录入：`asset-pipeline.md`、`critical-image-*.md`、`audio-assets.md`、`data-entry.md`、`game-config-package.md`。
- 协作与系统：`conversation-handoff-target-lock.md`、`worktree-branch-target-lock.md`、`feedback-system.md`、`global-systems.md`、`golden-rules.md`。

同一主题若还有 workflow，workflow 只描述执行顺序，规则判断仍以本目录为准。
