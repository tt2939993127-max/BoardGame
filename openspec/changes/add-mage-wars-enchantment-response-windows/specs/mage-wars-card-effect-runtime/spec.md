## ADDED Requirements

### Requirement: 法师战争结界响应必须绑定连续结算 frame

法师战争的法术反制和攻击逆转响应 MUST 绑定所属 resolution frame。响应窗口或交互不得独立持有施法 / 攻击的后续主链。

#### Scenario: 响应窗口结束后恢复同一笔施法或攻击

- **GIVEN** 一次施法或攻击在法术反制 / 回避攻击时机打开响应窗口
- **WHEN** 强制展示交互完成
- **THEN** 系统 MUST 从同一 resolution frame 继续执行取消、返还、摧毁、逆转或原攻击
- **AND** 不得根据最近一条事件重新猜测原施法 / 攻击上下文

### Requirement: 厄运必须反制快速法术并返还全部施法成本

`1825 厄运` MUST 只在附属目标生物施放并成功进入法术反制步骤的快速法术时触发。展示后，目标法术 MUST 被取消并返回其拥有者法术书，原施法者本次支付的全部法力 MUST 返还，厄运 MUST 被摧毁。

#### Scenario: 厄运反制快速法术

- **GIVEN** 一个生物附属了己方隐藏的 `1825 厄运`
- **AND** 该生物施放一个快速法术并进入法术反制步骤
- **WHEN** 厄运完成强制展示
- **THEN** 该法术不得进入法术结算
- **AND** 该法术返回其拥有者法术书
- **AND** 本次法术施放支付的全部法力返还给施法者
- **AND** 厄运进入其拥有者的弃牌堆

#### Scenario: 厄运不反制非快速或未成功施放的法术

- **GIVEN** 目标生物附属了 `1825 厄运`
- **WHEN** 施放的是标准法术、法术未通过施放校验，或法术已在更早步骤被取消
- **THEN** 厄运 MUST NOT 被展示或摧毁
- **AND** 法术书、法力和弃牌堆 MUST 保持原有结果

### Requirement: 法力失效必须反制对手控制的咒语或结界目标法术

`1901 法力失效` MUST 只在附属目标成为对手控制的咒语或结界类法术的合法目标并进入法术反制步骤时触发。展示后，目标法术 MUST 被反制，法力失效 MUST 被摧毁。

#### Scenario: 法力失效反制对手目标法术

- **GIVEN** 一个实体生物附属了己方隐藏的 `1901 法力失效`
- **AND** 对手控制的咒语或结界类法术以该生物为目标并进入法术反制步骤
- **WHEN** 法力失效完成强制展示
- **THEN** 目标法术 MUST 被反制且不得进入法术结算
- **AND** 法力失效进入其拥有者的弃牌堆

#### Scenario: 法力失效不反制己方法术或非目标法术

- **GIVEN** 一个生物附属了 `1901 法力失效`
- **WHEN** 目标法术由同一玩家控制、不是咒语 / 结界类，或没有实际以该生物为目标
- **THEN** 法力失效 MUST NOT 被展示或摧毁

### Requirement: 攻击逆转必须区分可回避与无法回避攻击

`1904 攻击逆转` MUST 在附属目标生物被攻击并进入回避攻击步骤时触发。可回避攻击展示后 MUST 被回避并交换攻击来源与目标；无法回避攻击展示后 MUST 只摧毁攻击逆转，不得交换来源 / 目标或产生额外攻击。

#### Scenario: 可回避攻击被逆转

- **GIVEN** 一个实体生物附属了己方隐藏的 `1904 攻击逆转`
- **AND** 一个可回避的攻击以该生物为目标并进入回避攻击步骤
- **WHEN** 攻击逆转完成强制展示
- **THEN** 原攻击 MUST 被回避
- **AND** 原目标成为新的攻击来源、原来源成为新的目标
- **AND** 交换后的攻击从同一 resolution frame 进入投掷骰子与伤害效果步骤
- **AND** 攻击逆转进入其拥有者的弃牌堆

#### Scenario: 无法回避攻击只摧毁攻击逆转

- **GIVEN** 一个实体生物附属了 `1904 攻击逆转`
- **AND** 无法回避的攻击以该生物为目标
- **WHEN** 攻击进入回避攻击步骤
- **THEN** 攻击逆转 MUST 被摧毁
- **AND** 原攻击来源与目标 MUST 不交换
- **AND** 原攻击继续按原攻击上下文结算

### Requirement: 强制展示不得被 pass 绕过

当上述三张牌满足触发条件时，响应窗口 MUST 处于强制展示状态。当前响应者在展示交互完成前不得使用 `RESPONSE_PASS` 或无关游戏命令关闭窗口。

#### Scenario: 强制响应拒绝 pass

- **GIVEN** `1825`、`1901` 或 `1904` 已满足触发条件且强制展示交互处于当前响应窗口
- **WHEN** 当前响应者提交 `RESPONSE_PASS` 或与该展示无关的游戏命令
- **THEN** 命令 MUST 被拒绝
- **AND** 原 resolution frame、结界状态、法术 / 攻击上下文不得被错误推进或清除

### Requirement: 结界响应必须实时绑定当前交互与 resolution frame

结界展示响应 MUST 在提交时重新校验当前 simple-choice interaction、响应者、active resolution frame、响应对象 ID 和响应卡牌 ID。旧交互、错误响应者、重复响应、错误来源或已删除/替换的 frame MUST 被拒绝，不得按交互创建时的静态选项继续结算。

#### Scenario: active frame 指向其它响应来源时拒绝展示

- **GIVEN** 当前展示交互仍存在
- **AND** active resolution frame 已被替换为其它响应对象或其它响应卡牌
- **WHEN** 玩家提交原展示选项
- **THEN** 响应 MUST 被拒绝
- **AND** 当前交互、响应窗口和原隐藏结界 MUST 保持未完成状态

#### Scenario: active frame 已删除时拒绝展示

- **GIVEN** 当前展示交互仍存在
- **AND** 其 active resolution frame 已被删除
- **WHEN** 玩家提交原展示选项
- **THEN** 响应 MUST 被拒绝
- **AND** 系统不得从旧交互快照继续摧毁结界、反制法术或逆转攻击
