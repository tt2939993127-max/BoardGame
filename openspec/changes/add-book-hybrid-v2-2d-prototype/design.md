## Context
此前 `book-hybrid` 一度转向 3D WebGL 书架，但该方向已被明确放弃。新的目标不是恢复 3D 效果，而是为“书本式游戏入口 / 本地素材展示”提供一个稳定、低复杂度、易迭代的 2D 开发页。

## Goals
- 将 `book-hybrid` 明确定义为纯 2D 原型页。
- 保持 `/dev/book-hybrid` 可作为唯一开发入口。
- 页面优先展示本地素材图片，而不是依赖外链资源或 WebGL。
- 没有素材时仍能稳定运行，并以占位内容退化。

## Non-Goals
- 不恢复或保留 3D WebGL 书架。
- 不要求复杂镜头、材质、后处理或 R3F 交互。
- 不把该页面升级为正式产品入口。

## Decisions
- Decision: 使用纯 DOM / CSS 作为主要实现形态
  - Why: 该页面目标是稳定验证书籍素材和分页结构，不需要额外的 3D 渲染复杂度。
- Decision: 素材位按书籍数据显式声明
  - Why: `cover`、`preview`、`background` 等字段更利于后续逐步替换真实本地图片，而不是把素材路径硬编码在视图层。
- Decision: 将“无素材时稳定退化”写入 spec
  - Why: 这是该页面最核心的运行质量底线，必须在需求层明示。

## Risks / Trade-offs
- 视觉冲击力会弱于 3D 方案，但实现与维护成本显著更低。
- 若未来重新引入动效，仍应保持在 2D 范围内，不要再次把核心目标漂移到 WebGL。

## Migration Plan
1. 以新的 2D change 作为唯一有效方向。
2. 后续实现时恢复 `/dev/book-hybrid` 页面，但仅按 2D 方案落地。
3. 书籍数据改为支持本地素材字段。
4. 通过本地素材和占位内容验证页面稳定性。
