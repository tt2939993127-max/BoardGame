## ADDED Requirements

### Requirement: 元素魔杖必须维护独立的绑定法术状态

`3716 元素魔杖` 的绑定法术 MUST 记录在具体装备对象上。绑定法术不得被写入当前计划法术列表，也不得因为绑定而进入弃牌堆。

#### Scenario: 装备施放时首次绑定

- **WHEN** 当前法师合法施放元素魔杖并提供一张属于自己法术书的非史诗攻击法术
- **THEN** 新建的元素魔杖装备对象 MUST 记录该法术定义 ID 为当前绑定法术
- **AND** 该绑定法术 MUST NOT 被加入当前计划法术列表或弃牌堆

#### Scenario: 装备施放时暂不绑定

- **WHEN** 当前法师合法施放元素魔杖但未提供绑定法术
- **THEN** 元素魔杖 MUST 进入场上且绑定状态为空

### Requirement: 元素魔杖替换绑定必须走快速施法能力

元素魔杖替换绑定 MUST 复用竞技场对象能力命令，并且只有附着在当前法师身上的元素魔杖可以在快速施法阶段支付固定 3 点法力发起替换。

#### Scenario: 合法替换绑定

- **WHEN** 当前玩家在快速施法阶段通过自己的元素魔杖选择另一张属于自己法术书的非史诗攻击法术，且拥有至少 3 点法力
- **THEN** 命令 MUST 成功并产生元素魔杖能力结算事件
- **AND** reducer MUST 把装备对象的绑定法术改为新法术
- **AND** 玩家法力 MUST 减少 3 点

#### Scenario: 非法替换被拒绝

- **WHEN** 请求来自未附着于当前法师的对象、非快速施法阶段、非法法术、相同绑定法术或法力不足
- **THEN** 命令 MUST 被拒绝且不得改变装备绑定、法力或弃牌堆

### Requirement: 元素魔杖资格必须来自结构化卡牌数据

绑定资格 MUST 使用法术书成员关系、结构化攻击类型和非史诗数据判断，不得从中文规则正文或展示文案推导。

#### Scenario: 非攻击或史诗法术不可绑定

- **WHEN** 玩家选择非攻击法术或带有史诗标记的法术绑定到元素魔杖
- **THEN** 校验 MUST 返回非法绑定法术错误
