# Change: 接入魔宠与再生点独立施法

## Why

规则书第 13、16、18 页定义了魔宠与再生点可以成为实际施法者，但当前 Mage Wars 基础运行时只有法师的玩家级计划牌和法力池。若直接把普通生物或玩家 ID 当作施法者，会错误计算范围、计划归属、法力支付和 `1804 法师祸咒`。

## What Changes

- 为配置卡录入魔宠 / 再生点的施法来源、允许的法术类型、行动时机和聚魔 / 对象法力规则。
- 为每个施法对象建立独立的单张计划法术，不与法师的两张计划法术共用同一个玩家槽位。
- 让魔宠在生物行动阶段、再生点在部署阶段，从对象自身法力优先支付，余额再由控制法师支付。
- 让施法命令显式引用施法对象，并用对象位置计算范围；被反制 / 取消时按规则返还计划与法力，来源在施法前被摧毁时销毁其计划牌。
- 在真实对象施法成功结算后放行 `1804`；法师施法、普通生物施法、取消 / 反制和来源失效不得触发。

## Scope

- 首批真实来源：Workshop 候选 `2908 乌鸦魔宠胡金` 与 `2218 巢穴`；`2905 花仙魔宠菲蕾拉`、`3017 灵婴魔宠瑟希利克斯` 已完成字段核读，但留到后续批次，避免首批同时扩大魔宠限制组合。
- 只接入该能力所需的来源卡字段和运行时链路，不承诺完整 322 张法术卡、自由构筑、四人模式、完整 AI 或完整 UI。
- 不从中文规则正文临时解析能力；配置卡、规则字段合同和正式 atlas/frame 是各自 owner。

## Impact

- Affected specs: `mage-wars`
- Affected code: 施法命令 / 验证 / 计划事件、场上对象状态、对象法力与施法入口、响应续链和 `1804` 触发。
- Affected data: 魔宠 / 再生点卡字段、法术书可用性、Workshop CardID 到 atlas frame 的正式映射。
