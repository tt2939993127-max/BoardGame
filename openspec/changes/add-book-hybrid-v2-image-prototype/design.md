## Context
`book-hybrid` 当前是开发态试验页，不承担正式线上产品能力。v2 的目标不是继续追求高成本 3D 沉浸效果，而是为“书本式游戏入口”提供一个稳定、可替换素材、可快速试错的视觉原型。

## Goals
- 使用纯 React + DOM + CSS 完成 `book-hybrid` 页面。
- 允许用本地素材图片快速替换封面、截图或装饰图。
- 将交互收敛到最小可运行闭环，降低运行时错误与渲染不确定性。

## Non-Goals
- 不实现 WebGL / Three.js / Canvas 程序化材质。
- 不实现复杂镜头推进、3D 翻书、物理动画或光影系统。
- 不把该原型页提升为正式大厅入口或正式设计系统规范。

## Decisions
- Decision: 页面只保留一个 dev 路由 `/dev/book-hybrid`
  - Why: 避免同类试验页并存，降低维护成本和误判。
- Decision: 所有视觉主体优先使用本地素材图片
  - Why: 这轮的核心目的是“试素材”，不是继续打磨纯代码生成的假材质。
- Decision: 交互以书籍切换和分页切换为主
  - Why: 这两个动作足以支撑素材验证，同时风险最低、最容易跑通。

## Risks / Trade-offs
- 素材质量会直接影响观感，但这是本轮需要验证的内容，不属于实现缺陷。
- 从 3D 降到 2D 后，沉浸感会下降，但换来更稳定的开发和更快的素材迭代速度。

## Migration Plan
1. 移除或停止导出旧 `book-2d` / `book-3d` 试验页。
2. 让 `/dev/book-hybrid` 成为唯一测试入口。
3. 在 `BookUIHybrid` 中定义素材位，允许逐步替换为真实图片。
4. 保持页面在没有新素材时仍能以占位内容稳定运行。
