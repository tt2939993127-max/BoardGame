# 设计：攻击法力流失配置

## Owner 边界

- `mage-wars.config.json` 保存每个攻击 profile 的法力流失静态数值。
- `configPackage.ts` 负责校验非负整数并物化。
- `spellRules.ts` 暴露对象攻击法力流失查询；配置对象不回读文本。
- `execute.ts` 继续负责实际伤害后的首段时机、目标控制方和法力封顶。

## 配置形状

```json
{
  "id": "attack-0",
  "manaDrain": 1
}
```

没有法力流失的 profile 不写字段，表示 0；不会把 0 写成展示文案。

## 迁移策略

1. 扩展攻击 profile 类型、校验和查询入口。
2. 录入 `2807` 两条攻击与 `3704` 两条攻击。
3. 将执行层扣法力调用切到对象 profile 查询。
4. 用首段、多段、法力不足封顶和无显示文本测试证明行为等价。
