## ADDED Requirements

### Requirement: 大杀四方局内设置提供专属偏好入口
系统 SHALL 在大杀四方局内设置面板中提供“大杀四方偏好”区块，统一承载该游戏的专属 UI 偏好。

#### Scenario: 打开大杀四方局内设置
- **GIVEN** 玩家正在大杀四方对局中
- **WHEN** 玩家打开局内设置面板
- **THEN** 面板 MUST 显示大杀四方专属偏好区块
- **AND** 该区块 MUST 至少包含“输入模式”和“英文卡图中文覆盖层”两项设置

### Requirement: 大杀四方支持点击模式与拖拽模式切换
系统 SHALL 为大杀四方提供互斥的 `click` 与 `drag` 两种主输入模式，并允许玩家在设置中切换。

#### Scenario: 默认保持现有点击模式
- **GIVEN** 玩家此前从未设置过输入模式
- **WHEN** 首次进入大杀四方对局
- **THEN** 系统 MUST 使用点击模式作为默认值

#### Scenario: 设置中切换输入模式
- **GIVEN** 玩家正在大杀四方对局中
- **WHEN** 玩家在设置中将输入模式从点击切换为拖拽，或从拖拽切回点击
- **THEN** 新模式 MUST 在当前会话中立即生效
- **AND** MUST 不要求刷新页面

### Requirement: 点击模式保留当前点击式出牌链路
系统 SHALL 在点击模式下保留当前大杀四方“点击手牌选中，再点击基地或随从完成打出”的主交互行为。

#### Scenario: 点击模式不回归
- **GIVEN** 当前输入模式为点击
- **WHEN** 玩家点击一张需要基地目标的手牌，再点击一个合法基地
- **THEN** 系统 MUST 与变更前一样完成打出
- **AND** MUST 继续使用现有合法目标高亮与命令入口

### Requirement: 拖拽模式支持桌面端与移动端一致的拖拽出牌
系统 SHALL 在拖拽模式下，同时为桌面端与移动端提供手牌拖拽到棋盘目标的主出牌交互。

#### Scenario: 桌面端拖拽到基地
- **GIVEN** 当前输入模式为拖拽
- **AND** 玩家手中有一张需要基地目标的手牌
- **WHEN** 玩家拖起该手牌并释放到合法基地
- **THEN** 系统 MUST 完成与点击模式等价的打出结果

#### Scenario: 移动端拖拽到随从
- **GIVEN** 当前输入模式为拖拽
- **AND** 玩家使用触摸设备操作
- **AND** 玩家手中有一张需要随从目标的手牌
- **WHEN** 玩家拖起该手牌并释放到合法随从
- **THEN** 系统 MUST 完成与点击模式等价的打出结果

### Requirement: 拖拽模式显示目标箭头与合法目标高亮
系统 SHALL 在拖拽模式中同时显示合法目标高亮与一条从被拖拽手牌指向目标的视觉箭头。

#### Scenario: 命中合法目标时显示箭头终点
- **GIVEN** 当前输入模式为拖拽
- **WHEN** 玩家拖动手牌并悬停到一个合法基地或合法随从之上
- **THEN** 系统 MUST 保持该目标的合法高亮
- **AND** MUST 显示一条指向当前目标的箭头

#### Scenario: 未命中目标时箭头跟随指针
- **GIVEN** 当前输入模式为拖拽
- **WHEN** 玩家拖动手牌但当前未命中任何合法目标
- **THEN** 箭头终点 MUST 跟随当前指针或触点位置
- **AND** 系统 MUST 不把非法目标显示为合法

### Requirement: 拖拽模式不得与点击模式主输入串扰
系统 SHALL 让点击模式与拖拽模式的主出牌输入互斥，避免用户在同一模式下同时触发两套主交互。

#### Scenario: 点击模式下轻微移动不触发拖拽出牌
- **GIVEN** 当前输入模式为点击
- **WHEN** 玩家点击手牌时产生轻微指针移动
- **THEN** 系统 MUST 继续按点击模式处理
- **AND** MUST 不启动拖拽出牌链路

#### Scenario: 拖拽模式下轻触手牌不进入点击部署流程
- **GIVEN** 当前输入模式为拖拽
- **WHEN** 玩家轻触一张手牌但未满足拖拽启动阈值
- **THEN** 系统 MUST 不进入当前点击模式的“选牌待部署”状态

### Requirement: 拖拽模式优先保证移动端拖拽，不与手牌查看手势冲突
系统 SHALL 在拖拽模式下优先保证移动端手牌拖拽操作，不得让手牌本体上的查看手势阻断主出牌流程。

#### Scenario: 移动端拖拽优先于手牌本体长按查看
- **GIVEN** 当前输入模式为拖拽
- **AND** 玩家使用触摸设备操作手牌
- **WHEN** 玩家从手牌本体开始拖动
- **THEN** 系统 MUST 优先进入拖拽链路
- **AND** MUST 不因为手牌本体长按查看而阻断拖拽

#### Scenario: 拖拽模式下仍可查看卡牌详情
- **GIVEN** 当前输入模式为拖拽
- **WHEN** 玩家使用显式查看入口请求查看手牌详情
- **THEN** 系统 MUST 仍然允许查看卡牌详情
- **AND** MUST 不要求切回点击模式后才能查看

### Requirement: 非法释放必须取消，不得误出牌
系统 SHALL 在拖拽模式下把非法释放视为取消，而不是猜测最近目标或自动改写命令。

#### Scenario: 释放到非法区域
- **GIVEN** 当前输入模式为拖拽
- **WHEN** 玩家拖起手牌后释放到任意非法区域
- **THEN** 系统 MUST 取消本次拖拽出牌
- **AND** MUST 不发送打出命令
