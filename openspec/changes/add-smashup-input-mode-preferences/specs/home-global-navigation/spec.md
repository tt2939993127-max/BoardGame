## ADDED Requirements

### Requirement: 首页全局入口按平台使用不同承载方式
系统 SHALL 为首页全局入口提供按平台区分的承载方式：手机首页使用面包屑式顶部导航，PC 首页继续使用悬浮球。

#### Scenario: 手机首页使用面包屑式导航
- **GIVEN** 用户处于首页
- **AND** 当前视口为手机尺寸
- **WHEN** 首页渲染全局入口
- **THEN** 系统 MUST 使用面包屑式顶部导航承载首页全局入口
- **AND** MUST 不再要求用户依赖首页悬浮球完成这些入口访问

#### Scenario: PC 首页保留悬浮球
- **GIVEN** 用户处于首页
- **AND** 当前视口为桌面尺寸
- **WHEN** 首页渲染全局入口
- **THEN** 系统 MUST 继续使用悬浮球承载首页全局入口

### Requirement: 手机首页面包屑式导航收纳登录与全局账户入口
系统 SHALL 在手机首页的面包屑式导航中收纳游客态与登录态常用入口，而不是把它们继续分散在页面角落。

#### Scenario: 游客态显示登录相关入口
- **GIVEN** 当前为手机首页
- **AND** 用户未登录
- **WHEN** 面包屑式导航展开或激活
- **THEN** 系统 MUST 提供登录与注册入口

#### Scenario: 登录态显示账户与社交入口
- **GIVEN** 当前为手机首页
- **AND** 用户已登录
- **WHEN** 面包屑式导航展开或激活
- **THEN** 系统 MUST 提供通知、社交、账户设置与全局设置入口

### Requirement: 首页全局入口与局内游戏专属偏好分层
系统 SHALL 区分首页全局入口与局内游戏专属偏好入口，避免把游戏专属设置错误塞进首页全局导航。

#### Scenario: 大杀四方专属偏好不挤入首页全局导航
- **GIVEN** 用户位于首页
- **WHEN** 系统渲染首页全局入口
- **THEN** 系统 MUST 不把大杀四方输入模式等局内专属偏好直接暴露为首页全局入口项
- **AND** 这些偏好 MUST 继续由对应游戏的局内设置入口承载
