## ADDED Requirements

### Requirement: 登录用户游戏 UI 偏好持久化
系统 SHALL 为登录用户持久化账号级游戏 UI 偏好，并允许按 `gameId` 读取对应游戏的偏好对象。

#### Scenario: 登录读取大杀四方偏好
- **WHEN** 登录用户进入大杀四方对局，且服务器已保存该账号的大杀四方 UI 偏好
- **THEN** 系统 MUST 读取该账号的 `smashup` 偏好
- **AND** MUST 将输入模式与卡图覆盖层应用到当前会话

#### Scenario: 登录更新大杀四方偏好
- **WHEN** 登录用户在大杀四方设置面板中修改输入模式或卡图覆盖层开关
- **THEN** 系统 MUST 将最新偏好写回账号级用户设置
- **AND** 当前会话中的 UI 状态 MUST 立即更新

### Requirement: 未登录用户游戏 UI 偏好仅保存在本地
系统 SHALL 在未登录状态仅通过本地缓存保存游戏 UI 偏好。

#### Scenario: 游客修改大杀四方偏好
- **WHEN** 未登录用户修改大杀四方输入模式或卡图覆盖层开关
- **THEN** 系统 MUST 仅更新本地缓存
- **AND** MUST 不发送账号级用户设置写入请求

### Requirement: 首次登录迁移本地游戏 UI 偏好
系统 SHALL 在用户首次登录且账号端不存在对应游戏 UI 偏好时，迁移当前本地缓存的游戏偏好。

#### Scenario: 账号无大杀四方偏好时迁移本地值
- **WHEN** 用户登录且服务器不存在该账号的大杀四方 UI 偏好
- **AND** 本地缓存中存在大杀四方输入模式或卡图覆盖层偏好
- **THEN** 系统 MUST 将当前本地大杀四方偏好写入账号级用户设置
- **AND** 后续登录会话 MUST 继续使用该账号偏好

### Requirement: 登录态应用账号偏好不得污染游客本地值
系统 SHALL 在登录态应用账号级游戏 UI 偏好时保留游客自己的本地缓存，以便登出后恢复游客偏好。

#### Scenario: 登出恢复游客本地大杀四方偏好
- **WHEN** 用户在登录态使用过账号级大杀四方偏好后退出登录
- **THEN** 系统 MUST 恢复该浏览器原有的游客大杀四方本地偏好
