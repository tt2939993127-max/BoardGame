## 当前验证链

1. `upgrade-masamune-2` 的两个关键分支已由 `src/games/dicethrone/__tests__/cross-hero.test.ts` 定向覆盖：
   - `masamune-2-large-straight`
   - `masamune-2-power-up`
2. `card-righteousness` 与 `card-zanshin` 已在 `src/games/dicethrone/heroes/samurai/cards.ts` 接线，并通过 `src/games/dicethrone/domain/customActions/samurai.ts` 承接真实结算。
3. `public/locales/zh-CN/game-dicethrone.json` 与 `public/locales/en/game-dicethrone.json` 已补齐相关名称与描述。

## 当前真实结论

1. `slot-24 / 正宗 II` 已不再属于“升级差异待核定”。
2. `slot-30 / 舍生取义！` 与 `slot-31 / 残心！` 已不再属于“待实现攻击修正卡”。
3. `slot-23 / 武道 II` 的 `8 damage` 已由本地卡图 OCR 再次支撑，和当前实现一致。
4. 本轮逐格重看 `slot-00 ~ slot-17` 后，确认武士通用牌顺序与枪手相同，`SAMURAI_COMMON_ATLAS_INDEX` 必须使用反向映射；旧正向写法已判定为 bug 并修正。
5. 武士卡牌线当前不再把 `Masamune II`、`Budo` 数值或通用牌索引作为主 residual。

## 当前真实 residual

1. 当前未再保留武士卡牌线的角色级 residual。
2. 后续若继续补图证，可把重点转到提示板 OCR 清晰度，而不是继续重复登记 `slot-24 / slot-30 / slot-31 / slot-23`。

## 当前运行时取图合同

不是把整套武士卡重新录一遍，而是把运行时取图收回到和老角色一致的 atlas 规格：

- 全部 `previewRef` 统一走 `previewRef.type = 'atlas'`
- atlas 使用 `ability-cards.webp`
- `slot-18 ~ slot-31` 直接作为武士专属卡运行时索引
- `slot-00 ~ slot-17` 也已按全量对图结果更新为反向通用牌映射，不再沿用默认公共 atlas 顺序
- 结论：
  - 索引已经更新，不再沿用旧 `hand-cards-atlas` 的 `0 ~ 13` 顺序
  - 需要改的是运行时取图映射，不是整套卡牌文本/数值重新录入
