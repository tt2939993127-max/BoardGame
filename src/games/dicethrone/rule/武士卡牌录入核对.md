## 当前真实结论

1. `slot-24 / 正宗 II` 已不再属于“升级差异待核定”。
2. `slot-30 / 舍生取义！` 与 `slot-31 / 残心！` 已不再属于“待实现攻击修正卡”。
3. `slot-23 / 武道 II` 的 `8 damage` 已由本地卡图 OCR 再次支撑，和当前实现一致。

## 当前真实 residual

2. 后续若继续补图证，可把重点转到提示板 OCR 清晰度，而不是继续重复登记 `slot-24 / slot-30 / slot-31 / slot-23`。
